# Minnesota Interstate Traffic Dashboard

Interactive traffic analytics dashboard created using Tableau.

## Dashboard Preview

![Dashboard Screenshot](traffic_dashboard.png)

## Tools Used

- Tableau Public
- CSV Dataset

## Key Metrics

- Traffic Volume by Weather
- Traffic Volume Over Time
- Traffic Volume by Holiday
- Traffic Volume by Hour of Day

## Key Insights

- Traffic volume peaks during commuting hours.
- Weather conditions influence traffic patterns.
- Holiday traffic differs from regular weekdays.
- Traffic trends change over time.

Source data included in:
- `traffic_data.csv`
