
# Minnesota Interstate Traffic Dashboard

## Project Overview

This project explores traffic volume patterns on
Minnesota's interstate highway system using
interactive data visualizations in Tableau.

The analysis examines how traffic volume varies
across different times of day, weather conditions,
holidays, and longer-term trends.

The goal is to identify traffic patterns and
present insights through an accessible,
interactive dashboard.

## Project Objectives

- Analyze traffic volume patterns over time.
- Identify peak traffic hours throughout the day.
- Explore traffic differences across weather conditions.
- Compare holiday and regular-day traffic patterns.
- Develop an interactive dashboard to communicate
  traffic trends clearly.

## Key Metrics

The dashboard focuses on four main analytical areas:

### 1. Traffic Volume by Weather
Examines differences in recorded traffic volume
across weather conditions.

### 2. Traffic Volume Over Time
Visualizes changes in traffic volume throughout
the observation period.

### 3. Traffic Volume by Holiday
Compares traffic patterns associated with
holidays and regular days.

### 4. Traffic Volume by Hour
Identifies variations in traffic activity
throughout the day.

## Key Findings

- **Peak Hours:** Traffic volume increases
  during typical commuting hours.

- **Weather Patterns:** Recorded traffic volume
  varies across different weather conditions.

- **Holiday Effects:** Traffic patterns differ
  between holidays and regular days.

- **Temporal Trends:** Traffic volume changes
  over time, revealing recurring patterns.

These findings describe patterns observed in the
dataset and do not establish causal relationships.
